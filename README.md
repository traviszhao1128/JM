Static multi-page site: `index.html` (home), `research.html`, `teaching.html`, `cv.html`, shared `style.css`. No build step, no dependencies beyond Google Fonts.

## Before going live — add these files

1. `assets/Zhao_CV.pdf` — your CV (export a real PDF; the current CV_2026 file is not a valid PDF).
2. `papers/Zhao_JMP_HedgeFund_USChina_Tension.pdf` — non-blind JMP with contact info on the title page.
3. `papers/Zhao_Informed_Option_Trading_Data_Breaches.pdf` — the options paper.

File names must match exactly (links on the pages point to these paths), or edit the links.

## Deploy on GitHub Pages (recommended — free, fast, permanent URL)

1. Create a GitHub account if needed, then a new **public** repository named `<username>.github.io`.
2. Upload all files and folders from this directory to the repository (drag-and-drop works on github.com → "Add file" → "Upload files").
3. Wait 1–2 minutes. The site is live at `https://<username>.github.io`.

Updating later: upload the changed file again; it replaces the old one.
